### About Me

I am a Penetration Tester and Backend Engineer with 3+ years of experience building Python-based systems and APIs.

My work bridges software development and offensive security. My backend experience helps me understand application internals, identify security weaknesses, and provide practical remediation guidance. All security assessments are performed within explicitly authorized scopes.

- Creator and maintainer of **EcoTrace**, an open-source Python library for measuring runtime energy consumption and carbon emissions.
- Creator of **RedAgent**, an open-source platform for assessing security risks in LLM-powered applications.
- Focused on web application security, network reconnaissance, vulnerability validation, and AI/LLM security.
- Interested in secure backend architecture and practical security automation.
